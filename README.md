# EveryWare Landing Page

EveryWare is a modern, premium landing page designed for the EveryWare smart home service mobile application. Developed using React, Vite, Framer Motion, and Three.js, it showcases the application's unique features with a high-fidelity, fluid glass aesthetic.

## 🚀 Technology Stack

- **Core**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/) for fluid page transitions, card entry offsets, and viewport scroll reveals
- **3D Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) for background particle animations
- **Icons**: [Lucide React](https://lucide.dev/) for crisp, scalable vector graphics
- **Typography**: [Oxygen Google Font](https://fonts.google.com/specimen/Oxygen) applied globally

## ✨ Core Features & Sections

- **Dynamic Hero Canvas**: Interactive 3D glass shapes that float naturally in the background, layered behind the hero title.
- **Fluid Morphism Navbar**: A glassmorphic capsule navigation bar that dynamically scales when scrolled and centers the active indicator capsule.
- **Auto-playing Live Tracking**: High-performance, uncropped vertical portrait simulation showcasing real-time GPS tracking of assigned technicians at 60/120fps.
- **AI Copilot Simulator**: Interactive chatbot display showcasing automated symptom diagnosis and technician assignment.
- **Appliance Health Panel**: Isolated, clean visualization of household appliance metrics and upcoming maintenance alerts.
- **Interactive FAQ Widget**: Click-response tab switcher utilizing framer-motion crossfade animations for premium detail reveal.
- **Spacious Footer Card**: Large integrated cyan download banner container replacing static text placeholders at the top of the footer columns.

## 🛠️ Local Development

To run the project locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the local development server:
   ```bash
   npm run dev
   ```

3. Build the production application bundle:
   ```bash
   npm run build
   ```
