# T-01-015 — Branded 404 page

**Spec:** 01-foundation §5.3
**Depends on:** T-01-014
**Estimate:** ~0.5h

## What to build

`src/pages/404.astro` using `BlogLayout`: a single `<h1>`, a short explanation, and links back to
`/blog` and `/`. Unknown blog slugs are never generated, so Vercel serves this file for them.

## Acceptance criteria

- [ ] `npm run build -w apps/blog` emits `apps/blog/dist/404.html`.
- [ ] It contains exactly one `<h1>` and links to both `/blog` and `/`.
- [ ] It renders header and footer consistently with the rest of the blog.
- [ ] It ships no JavaScript.
