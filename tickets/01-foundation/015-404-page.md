# T-01-015 — Branded 404 page

**Spec:** 01-foundation §5.3
**Depends on:** T-01-014
**Estimate:** ~0.5h

## What to build

`src/pages/404.astro` using `BlogLayout`: a single `<h1>`, a short explanation, and links back to
`/blog` and `/`. Unknown blog slugs are never generated, so Vercel serves this file for them.

## Acceptance criteria

- [x] `npm run build -w apps/blog` emits `apps/blog/dist/404.html`.
- [x] It contains exactly one `<h1>` and links to both `/blog` and `/`.
- [x] It renders header and footer consistently with the rest of the blog.
- [x] It ships no JavaScript.

## Status

**Done** — commit on `feat/everyware-blog-platform`. 152 tests.

### Note

`404.html` is now excluded from the whole-site assertion sweeps in
`build-output.test.ts` and given its own tests instead. It is served for URLs
that do not exist, so site-wide claims like "one file per published post" and
"every internal link resolves to a real article" do not apply to it — folding it
into those sweeps would have meant weakening them for every other page.
